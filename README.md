## Install
Clone the repo and copy the contents into ~/.config

```
# Clone the repo
git clone https://github.com/bodersthesharknardoragon/hyprland-config

# Copy contents to ~/.config
cd hyprland-config
rclone copy -i . ~/.config
```

## Update
Go to ~/.config and pull latest changes

```
cd ~/.config
git pull
```
